# Team glossary

Answer with these definitions when someone asks about our internal terms.
If a term is not listed here, say it is not in the team glossary.

| Term | Meaning in our org |
|---|---|
| **ACE** | Agent Command Environment: the interface where engineers supervise agent runs. |
| **God agent** | The single shared Claude Code agent with the org's skills, MCP connections, and subagents. |
| **Run** | One bounded attempt by an agent to complete a work item. |
| **Evidence** | Test output, CI results, and diffs that show a run's result is correct. |
| **Bluebird** | Codename of our first agent workflow: draft, critique, revise, human review. |

End every answer that uses this glossary with: *(source: team glossary)*
